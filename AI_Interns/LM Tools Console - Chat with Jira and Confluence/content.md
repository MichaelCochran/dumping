1. EO Software & Data Engineering teams' knowledge is scattered across Jira, Confluence, and GitLab.
2. Simple questions (latest spec, related Jira work, MOF story alignment) require manual cross-referencing and redundant communication across teams.
3. Onboarding, design reviews, audits, and daily cross-collaboration are slowed by document chasing instead of analysis.
4. There is no safe way today to ask an AI agent for a consolidated, traceable answer without touching production Jira/Confluence data.
Attachments (2)**71CABB18-815F-11F1-8DAC-0E70A83EB993.png680.66KBagent_prototype_presentation.pptx991.21KB**Organization / Team*Team AIM AIC 2026 Solution Overview*
LM Tools Console - An agentic interface that operates and aggregates across Confluence, Jira, and Gitlab. 
- AI assistant powered by a Model Context Protocol (MCP) read-only server over Jira and Confluence.
- Uses Genesis AI Factory models to drive tool use and synthesize answers.
- Accessible from the LM Tools Console UI and MCP-compatible clients.

Value Proposition*
-** Faster Discovery**: Lookup time drops from 30–60 minutes per interface to seconds, letting engineers and interns instantly retrieve the latest spec, related Jira work, and Jira story alignment.

- **Reduced Onboarding**: New engineers gain immediate, traceable visibility into complex tool ecosystems without learning navigation across three platforms.

- **Improved audit readiness**: Governance partners run repeatable, read-only queries over authoritative sources, reducing accidental change risk while accelerating evidence collection.
Additional Information
See this video to setup and run the tool with access to the knowledge sources and visit this Gitlab repo to clone the necessary code to run it.
